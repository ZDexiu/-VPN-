# -VPN-
对用过的-fangqiang-VPN评价


## 狗狗加速

**官网**：https://狗狗加速.com/

### 评价
> 1. 购买时需额外支付手续费，金额在 4～7 元不等。  
> 2. 节点覆盖区域较广，但多数节点响应速度一般，且被污染情况较严重。  
> 3. 该服务主动屏蔽了 IP 地址检测网站，这种做法在其他加速器中较为罕见。

### 小结
**总体不推荐**，建议小伙伴们谨慎考虑，暂勿充值！


## FLYINGBIRD（飞鸟）

**官网**：https://a01.fbaffb05.cc/user

### 评价
> 1. 官方客户端，用账号密码登录
> 2. 节点有时候延迟很高。延迟不高的时候，选了也不一定能用。
> 3. 月费价格实惠是唯一优点。

### 小结
**总体不推荐**，建议小伙伴们偶尔用用可以，不能作为长期稳定使用的软件！


## 悦通（Yue.to）

**官网**：https://my.yue.to/#/login

### 评价
> 1. 官方客户端，用账号密码登录；也可以用clash-verge
> 2. 节点有时候延迟很高。延迟不高的时候，选了也不一定能用。
> 3. 月费价格实惠是唯一优点。但是有手续费，13%。不充值连节点都看不到。

### 小结
**总体不推荐**，建议小伙伴们不要用，目前用过最垃圾的一款了，基本只有香港节点能用，那有何用呢！


## 糖果云

**官网**：https://candytally.cyou/web/#/planDetail/5

### 评价
> 1. 官方客户端，用账号密码登录。
> 2. 第一次登录就发现节点全部超时，根本没法用。
> 3. 月费价格实惠是唯一优点。暂时没有有手续费。

### 小结
**总体不推荐**，建议小伙伴们不要用，没有最垃圾，只有更垃圾！
